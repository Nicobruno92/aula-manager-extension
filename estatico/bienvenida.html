Antes de usar la extensión

Esta extensión completa la carga de notas de SIU-Guaraní y de las actas del CBC con las notas que vos mandás desde Aula Manager. Esto es lo que hace con esos datos:

  • Qué recibe: el DNI de cada alumno y los datos del acta (fecha, parciales, nota, resultado y condición). Ningún nombre.
  • De dónde: solo de aula-manager.com, cuando tocás «Mandar a la extensión».
  • Dónde quedan: en la memoria de este navegador, nunca en el disco. Se borran a las dos horas, al cerrar Chrome o con «Borrar las notas guardadas».
  • Para qué: solo para completar el formulario de la página de carga de notas que vos abrís, cuando tocás «Usar en esta página». Vos revisás y guardás.
  • A quién se mandan: a nadie. La extensión no se conecta a ningún servidor y no comparte, vende ni usa estos datos para otra cosa.

El uso de los datos cumple la política de uso limitado de la Chrome Web Store. El código es público: github.com/Nicobruno92/aula-manager-extension.
